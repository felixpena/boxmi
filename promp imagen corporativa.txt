Construye la landing page completa de Boxmi en un único archivo index.html (HTML vanilla, sin frameworks, sin dependencias externas excepto Google Fonts).

---

CONTEXTO DEL PRODUCTO
Boxmi es una startup chilena de lockers inteligentes para condominios residenciales. Automatiza la recepción de paquetes y elimina la dependencia del conserje para esa tarea. Se vende a inmobiliarias y constructoras como equipamiento base de proyectos nuevos.
Tagline: "El edificio que ya esperaban."

  · Ahorro mensual = costo conserjería − costo Boxmi
  · Ahorro anual = ahorro mensual × 12
- Mostrar en tiempo real: dos columnas "Sin Boxmi" vs "Con Boxmi" con animación de número contando

REQUISITOS TÉCNICOS
- Un solo archivo index.html
- CSS en <style> en el <head>
- JS en <script> antes del </body>
- Responsive: mobile-first, breakpoints 768px y 1200px
- Sin jQuery, sin Bootstrap, sin React
- Google Fonts via @import en CSS
- scroll-behavior: smooth
- Animación del locker en hero: CSS keyframes únicamente
- Contador animado en calculadora: JS vanilla con requestAnimationFrame
- Formulario: validación HTML5 + confirmación JS inline

---

ESTÉTICA DE CÓDIGO
- Semántica HTML5 (section, nav, main, footer, h1/h2/h3)
- Variables CSS para colores y tipografía en :root
- Sin inline styles salvo casos excepcionales
- Comentarios de sección en el HTML
